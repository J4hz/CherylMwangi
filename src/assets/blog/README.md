# Blog images

Teaching and training graphics, kept here for use in blog posts. Nothing in this folder is
referenced by the site yet.

## Clear before publishing

Every file here needs Cheryl's confirmation that it is hers to use before it appears in a
published post under her name. Two need more than that:

- **`iceberg model.jpg`** — appears to be a stock illustration rather than an original diagram.
  Confirm licensing before publishing.
- **`3 yr old.jpg`** — the widely circulated "normal vs. extreme neglect" brain-scan training
  graphic. It is reproduced constantly without attribution and its provenance is often stated
  incorrectly. Confirm sourcing and permission before publishing it under Cheryl's name.
- **`Joharis window.jpg`**, **`How do i feel right now.jpg`** — confirm these are Cheryl's own
  training materials and not a third party's handouts.

## Using one in a post

Import it in the post's component, or add an `image` field to the post in
`src/content/posts.js` once a post actually needs one. Always write real alt text — these are
teaching diagrams, so the alt text should describe what the diagram teaches, not just name it.
